# سجل إعادة تهيئة Firebase لتسجيل الدخول والمزامنة

التاريخ: 2026-08-22.

## النطاق والمرجع

يقتصر هذا السجل على تهيئة Firebase لمساري تسجيل الدخول والمزامنة. بقي كود التطبيق والمستودع وتاريخ Git كما هي، ولم يُحذف `index.html` أو `client/index.html` ولم يُعاد بناء التطبيق من الصفر.

المستودع `SoliMedical/1` كان عند commit `689d103` قبل ربط المشروع الجديد، مع وجود الوسم المحلي `pre-firebase-rebuild-v1.8.4` كمرجع أرشيفي.

## المشروع الجديد

أُنشئ مشروع Firebase باسم `Soli Medical Sync` ومعرّف `soli-medical-sync`، مع تطبيق Web باسم `Soli Medical Web`. تم تعطيل Analytics لأن نطاق العمل الحالي هو تسجيل الدخول والمزامنة فقط.

أُنشئت قاعدة Firestore الافتراضية في وضع Native وبإصدار Standard وموقع `eur3` (Belgium and Netherlands). نُشرت قواعد المستودع المقيدة بنجاح؛ لا تسمح القواعد بالوصول العام ولا تسمح للمتصفح بإنشاء أو تعديل عضويات المستخدمين.

فُعّل مزود Authentication من نوع Email/Password فقط. بقيت Email Link وPhone وAnonymous وباقي المزودات غير مفعلة.

أُضيف نطاق GitHub Pages `solimedical.github.io` إلى قائمة Authorized domains للمشروع الجديد.

## هوية المدير والعضوية

أُنشئت هوية المدير في Firebase Authentication بالبريد الداخلي `admin@solimedical.local`، بينما يستمر المستخدم في واجهة التطبيق باستعمال اسم المستخدم المحلي `admin` وكلمة المرور التي أنشأها بنفسه. لا تُحفظ كلمة المرور في المستودع أو هذا السجل.

أُنشئت عضوية المدير في المسار `clinics/shared-clinic-v1/members`، وبها الحالة `active` والدور `owner` والربط المحلي `localUserId: 1` والبريد الداخلي المطابق. لم تُنشأ أي وثائق مرضى أو زيارات تجريبية يدويًا.

## إعداد التطبيق

تم تحديث `firebase-config.js` محليًا ليربط التطبيق بالمشروع الجديد باستخدام إعدادات Web العامة فقط. بقيت بوابة إدارة الحسابات Admin SDK معطلة مؤقتًا (`clinicAccountGatewayUrl` فارغ) حتى تتوفر خدمة خلفية جديدة وموثوقة للمشروع الجديد؛ لا توجد بيانات اعتماد Admin SDK في العميل أو المستودع.

تم رفع رقم التطبيق محليًا إلى v1.8.5 ورقم ذاكرة Service Worker إلى v36، مع إبقاء النسختين الجذرية والمصدرية متطابقتين. التغييرات لم تُدفع إلى `main` حتى اكتمال اختبار الدخول والمزامنة على GitHub Pages.

## حالة المشروع القديم

المشروع القديم `clinic1-ba255` ما زال موجودًا ولم يُحذف. سيبقى محفوظًا إلى أن ينجح اختبار المشروع الجديد فعليًا، ثم لا يُتخذ أي إجراء حذفه إلا بعد موافقة نهائية مستقلة.

## فحوصات محلية

اجتاز الإصدار المحلي فحص JavaScript المضمن، وفحص TypeScript، و115 اختبارًا في 16 ملفًا، وفحص البناء، وفحص المستودع، وحاجز الإصدار على `origin`، وفحص اختلافات Git، والتحقق من تطابق نسخ HTML وService Worker.

تظهر أثناء البناء تحذيرات Vite المعتادة بشأن ملفات JavaScript الكلاسيكية `firebase-config.js` و`soli-interface-enhancements.js` التي لا تحمل `type="module"`؛ لم تمنع البناء ولا تتعلق بتسجيل الدخول أو المزامنة.
