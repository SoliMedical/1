# فحص بصري — صفحة مبيعات Soli Medical

**التاريخ:** 17 أغسطس 2026  
**المسار المفحوص:** `/sales/`

تمت معاينة صفحة المبيعات بعد تحويل رابط واتساب إلى اسم المستخدم `Ahmed0soliman`. على سطح المكتب، ظهر التخطيط بترتيب واضح: القسم التعريفي، بطاقات الخصائص، قسم التخصصات، نموذج طلب العرض، ثم دعوة التواصل الختامية. ظهر النموذج بمدخلات مقروءة ومسافات مناسبة دون تداخل.

وعلى شاشة هاتف بعرض 375 بكسل، انطبقت البطاقات وحقول النموذج في عمود واحد دون قص أو تمرير أفقي. زر واتساب العائم لم يُقاس في لقطة الصفحة الكاملة لأن المعاينة تخفي العناصر الثابتة غير العلوية تلقائياً، لكن وجوده واستخدام رابط اسم المستخدم مغطى باختبار الانحدار `server/salesLanding.test.ts`.

## تحقق النشر العام

نجح نشر GitHub Pages للالتزام `c6ff33a`. عند فتح الرابط الأصلي من متصفح كان يحمل نسخة مخزنة مؤقتاً، ظهرت النسخة السابقة؛ وعند فتح الرابط مع معامل مراجعة `?v=c6ff33a` ظهرت النسخة الحديثة وتأكد وجود رابط التنقل إلى طلب العرض، والنموذج، وزر واتساب العائم، واسم المستخدم `Ahmed0soliman`. لذلك يوصى بتحديث الصفحة تحديثاً قسرياً أو فتح رابط المراجعة مرة واحدة عند استمرار ظهور النسخة القديمة من التخزين المؤقت المحلي.
