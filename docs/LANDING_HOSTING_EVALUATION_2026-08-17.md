# تقييم استضافة صفحة الهبوط خارج GitHub Pages

**التاريخ:** 17 أغسطس 2026

تم فحص الرابط المدمج الحالي للمشروع: <https://medicenter-h9mjj4tn.manus.space/sales/>. أعاد الرابط صفحة الدخول إلى تطبيق العيادة، لا صفحة المبيعات؛ لأن خدمة المسار `/sales/` الحالية مخصصة لمعاينة Vite ولا تشحن ضمن نشر التطبيق المدمج القائم.

لذلك لم يكن هذا الرابط يصلح كبديل مباشر لـ GitHub Pages قبل تهيئة مسار إنتاج لملفات صفحة المبيعات.

تمت إضافة خطوة بناء صريحة تنسخ `sales/index.html` إلى `dist/public/sales/index.html`. لذلك أصبح مسار الإنتاج المستهدف لصفحة الهبوط المستقلة هو:

`https://medicenter-h9mjj4tn.manus.space/sales/`

لا يعتمد هذا الرابط على GitHub Pages. تستخدم الصفحة نفس روابط الأصول الدائمة ونفس نموذج طلب العرض ورابط واتساب باسم المستخدم.

## النطاق المخصص

يمكن ربط نطاق مخصص من لوحة إدارة المشروع عبر **الإعدادات ← النطاقات**. بعد إضافة النطاق وربطه بالاستضافة المدمجة، يظل مسار صفحة الهبوط هو `/sales/`، مثل: `https://your-domain.example/sales/`.
