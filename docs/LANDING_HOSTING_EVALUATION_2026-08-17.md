# تقييم استضافة صفحة الهبوط خارج GitHub Pages

**التاريخ:** 17 أغسطس 2026

تم فحص الرابط المدمج الحالي للمشروع: <https://medicenter-h9mjj4tn.manus.space/sales/>. كان يعيد سابقاً صفحة الدخول إلى تطبيق العيادة بدلاً من صفحة المبيعات؛ لأن المسار العام في بيئة Vite كان يلتقط طلب `/sales/` قبل أن يصل إلى ملف صفحة المبيعات.

لذلك لم يكن هذا الرابط يصلح كبديل مباشر لـ GitHub Pages قبل تهيئة مسار إنتاج واضح لملفات صفحة المبيعات وتثبيت المسار نفسه قبل التوجيه العام في بيئة المعاينة.

تمت إضافة خطوة بناء صريحة تنسخ `sales/index.html` إلى `dist/public/sales/index.html`. كما أضيف مسار صريح لـ `/sales` و`/sales/` قبل الملفات الثابتة ومسار التطبيق الاحتياطي في الإنتاج، وقبل مسار Vite العام في المعاينة. أُعيد بناء المشروع، ونجح اختبار الانحدار المخصص، وتأكدت المعاينة محلياً من ظهور صفحة المبيعات بدلاً من شاشة الدخول. لذلك أصبح مسار الإنتاج المستهدف لصفحة الهبوط المستقلة هو:

`https://medicenter-h9mjj4tn.manus.space/sales/`

لا يعتمد هذا الرابط على GitHub Pages. تستخدم الصفحة نفس روابط الأصول الدائمة ونفس نموذج طلب العرض ورابط واتساب باسم المستخدم.

## النطاق المخصص

يمكن ربط نطاق مخصص اختياري من لوحة إدارة المشروع عبر **الإعدادات ← النطاقات**. يظل التطبيق الرئيسي على الرابط نفسه، وتبقى صفحة المبيعات على المسار الثابت `/sales/` بعد الربط.

| الخطوة | الإجراء المطلوب |
|---|---|
| 1 | افتح لوحة مشروع **Soli Medical** ثم انتقل إلى **الإعدادات ← النطاقات**. |
| 2 | أضف اسم النطاق الذي تملكه، مثل `solimedical.example`. |
| 3 | انسخ سجل DNS الذي تعرضه لوحة المشروع وأضفه لدى مزود النطاق. لا تحذف السجلات الأخرى إلا إذا طلبت اللوحة ذلك صراحة. |
| 4 | انتظر حتى يظهر تأكيد الربط في لوحة النطاقات، ثم افتح الرابط العام في نافذة خاصة للتأكد من عدم استخدام نسخة مخزنة قديمة. |
| 5 | استخدم رابط الحملة النهائي بالشكل `https://your-domain.example/sales/`، ثم اختبر زر واتساب العائم ونموذج طلب العرض. |

> **مهم:** لا يلزم تحويل الصفحة الرئيسية للنطاق إلى صفحة المبيعات. يبقى المسار `/sales/` واضحاً ومناسباً للإعلانات والمنشورات، فيما يمكن الاستمرار في استخدام مسار التطبيق الرئيسي وفق إعدادات المشروع.

## قائمة تحقق قبل مشاركة الرابط في الحملة

تحقق من فتح `https://your-domain.example/sales/` من هاتف وكمبيوتر، ومن ظهور رابط واتساب باسم المستخدم **Ahmed0soliman**، ومن أن النموذج يفتح رسالة جاهزة في واتساب دون تخزين بيانات العميل على خادم المشروع. بعد ذلك يُستبدل رابط GitHub Pages في أي حملة جديدة بالرابط المستقل أو بالنطاق المخصص عند اكتمال ربطه.
