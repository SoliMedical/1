# تشخيص مزامنة GitHub Pages — v1.5.5

**تاريخ الفحص:** 20 أغسطس 2026

## النتيجة النهائية

كان موقع GitHub Pages الرسمي `https://solimedical.github.io/1/` يعرض الإصدار **v1.5.4**، بينما تعرض نسخة Manus المنشورة الإصدار **v1.5.5**. إعداد GitHub Pages صحيح: الفرع `main` والمجلد الجذري `/`، وآخر سير Pages ناجح قبل الإصلاح كان مبنياً على التزام v1.5.4.

السبب المباشر لم يكن كثرة الملفات؛ بل كان مرجع الدفع المحلي `user_github` موجهاً إلى **SoliMedical/2** بدلاً من المستودع الرسمي **SoliMedical/1**. لذلك لم تصل التزامات v1.5.5 إلى `SoliMedical/1/main`، حتى إن كانت منشورة بنجاح على نطاق Manus.

صُحح المرجع إلى `https://github.com/SoliMedical/1.git`، ثم دُفعت سلسلة التزامات آمنة متقدمة من `75c1779` إلى `ea250e5`. اكتمل سير GitHub Pages بنجاح، وتحقق الموقع الحي من ظهور **v1.5.5**.

## تصنيف الملفات

| الفئة | المسارات | القرار |
|---|---|---|
| تشغيل GitHub Pages | `index.html` و`sw.js` و`manifest.webmanifest` و`firebase-config.js` وملفا تعزيز الواجهة و`assets/` | ملفات مطلوبة؛ لا تُنقل أو تُحذف. |
| نشر آلي | `.github/workflows/pages.yml` و`scripts/check-repository.mjs` | ملفات مطلوبة؛ تؤكد سلامة المستودع ثم تنشر الجذر. |
| تطوير واختبارات | `client/` و`server/` و`shared/` و`drizzle/` و`scripts/` و`tools/` وملفات الإعداد و`package.json` | لا تظهر مباشرة في واجهة Pages، لكنها لازمة للتطوير والاختبارات والبناء؛ لا تُحذف. |
| توثيق وسجل عمل | `docs/` و`README.md` و`ARCHITECTURE.md` و`FIREBASE_SYNC_GUIDE_AR.md` وملفات التحقق والملاحظات وملفات TODO | لا تؤثر في إصدار الواجهة، ويمكن أرشفة بعض السجلات بعد موافقة صريحة دون معالجة سبب النشر. |
| مواد متخصصة | `sales/` و`patches/` | لا تُحذف دون مراجعة منفصلة؛ قد تتصل بصفحة تسويقية أو توافق الاعتماديات. |

## ملاحظة مهمة عن الحجم

يستخدم سير GitHub Pages الحالي `path: .`، أي يرفع كامل المستودع كحزمة نشر. ومع ذلك لا ينفذ المتصفح إلا الملفات التي يستدعيها `index.html`. كثرة ملفات التوثيق قد تزيد حجم الحزمة قليلاً، لكنها لم تكن سبب تأخر تحديث v1.5.5؛ فالسبب كان اتجاه الدفع الخاطئ.

## منع تكرار المشكلة

عند كل إصدار جديد: تحديث `client/index.html` أولاً، مزامنة الملفات الجذرية، التحقق من `user_github` أنه يشير إلى `SoliMedical/1`، دفع `main`، ثم انتظار نجاح `pages.yml` والتأكد من رقم الإصدار الظاهر في الرابط العام.
